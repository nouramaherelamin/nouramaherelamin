## About Me

Computer Sciences & Information Systems student who works across the full pipeline of data-driven products: extracting insights from data (**Analysis & Machine Learning**), then building the interfaces that put them to use (**Web Development**).

I like understanding what the data says, and building the tools that make it usable. Rather than limiting myself to one technology or career path, I focus on building a strong technical foundation and developing the ability to learn, adapt, and apply new tools to real problems.

This profile reflects my current journey and is designed to grow alongside it.
